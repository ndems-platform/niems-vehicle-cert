# ระบบสร้างหนังสือรับรองมาตรฐานรถบริการการแพทย์ฉุกเฉิน

## NIEMS Certificate Vehicle Generator

ระบบสำหรับสร้างหนังสือรับรองมาตรฐานรถบริการการแพทย์ฉุกเฉิน สถาบันการแพทย์ฉุกเฉินแห่งชาติ (สพฉ.)

### คุณสมบัติ

- 📤 อัปโหลดไฟล์ Excel (.xlsx, .xls) หรือ CSV
- 📋 ตรวจสอบและเลือกข้อมูลที่ต้องการพิมพ์
- 📄 Preview หนังสือรับรองก่อนพิมพ์
- 🖨️ พิมพ์เป็น PDF คุณภาพสูง

### การติดตั้ง

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/niems-cert-vehicle.git
cd niems-cert-vehicle

# ติดตั้ง dependencies
npm install

# รัน development server
npm run dev
```
